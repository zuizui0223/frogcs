# 雨・植生・水域タイプの独立資料による再実行

2026-10-26。NAAMPの鳴き声集中を中心に据え、環境仮説を別資料でも点検した。これは独立資料での関連の確認であり、NAAMP残差の環境成分を差し引く解析ではない。元の公表済みファイルをチェックサムで確認し、既存スクリプトを変更せず再実行した。結果・ソースハッシュは同じフォルダのJSON、実行環境・コードハッシュは `replay_receipt.json` に保存した。

## ハンガリー：雨、局所水深、管理区分、植生

29湿地・129音声調査・40陽性・26調査日。湿地を分けた評価のBrierスコアは低いほど良い。

| 比較 | Brier |
|---|---:|
| W0：天候・季節 | 0.206304 |
| W1a：W0＋水深 | 0.203170 |
| W1b：W0＋管理・造成区分 | 0.180006 |
| W1：W0＋水深＋管理・造成区分 | 0.173773 |
| W2：W1＋抽水植物被度 | 0.177577 |
| W2alt：W1＋沈水植物被度 | 0.184995 |
| W3：W1＋両植生＋植物多様性 | 0.192719 |

W1のW0に対する改善は0.032531、区間[0.008798, 0.055849]。水深単独の改善区間は0をまたぎ、管理・造成区分の寄与もあるため、この改善全体を水深の効果と呼ばない。抽水植物追加の改善は−0.003804、区間[−0.009629, 0.001865]。抽水植物被度と雨×抽水植物の交互作用を同時追加した比較も−0.003711、区間[−0.009585, 0.002417]で改善を確認できなかった。

植生の生物学的効果がないと証明したものではない。29湿地の観察研究であり、相関・測定精度・標本数の限界がある。視覚観察ではW1のBrierは0.209378、W0は0.195621で、音声結果と一致しない。方法を混ぜて一般化しない。管理・造成区分は水域持続性そのものではない。

## NPS：水域タイプと過去の強い鳴き声

元音声資料147,913行、66地点、7公園、13分類群、2016–2023年。前年までの履歴と観測努力を用い、公園×分類群×年内の比較が可能な1,815行・195層・38再標本化ブロックで再実行した。応答は強い鳴き声（CI≥2）。

過去の自種の強い鳴き声との関連係数は、一時的水域0.3523 [0.2516, 0.4417]、半恒久的水域0.5022 [0.3961, 0.6028]、恒久的水域0.4950 [0.4112, 0.5676]。一時的水域との差はそれぞれ0.1500 [0.0436, 0.2633]、0.1428 [0.0450, 0.2426]。

水域タイプによる履歴関連の違いと整合する。ただし公園×種×年をさらに厳しく揃えた一時的水域内の比較は、履歴変動不足で推定不能という既存判定も保持した。これは個体の帰還、繁殖成功、競争の効果ではない。分類上の水域持続性であり、実測の時系列水位でもNAAMP地点のNWI分類でもない。

## 再実行

リポジトリルートから以下を実行した（出力先だけ別にした）。

```text
python research/scripts/hungary_rain_vegetation_site_allocation.py --out ../hungary_replay.json
python research/scripts/hungary_vegetation_chorus.py --output ../hungary_full_replay
python research/scripts/nps_hydroperiod_strict_history.py --output ../nps_hydro_replay
```

NAAMP集中残差の解釈では、局所環境の未測定部分、音声検出、同種の同期、他種との相互作用を競合する説明として残す。これらの別資料の係数をNAAMPに直接転用しない。
