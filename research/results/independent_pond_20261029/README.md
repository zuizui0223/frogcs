# Independent alpine-pond source audit

Lamouille-Hébert, M., Arthaud, F., Besnard, A., Logez, M. & Datry, T.
*Increased drying threatens alpine pond biodiversity more than temperature increase in a changing climate.* Aquatic Sciences 87, 25 (2025; online 2024).
https://doi.org/10.1007/s00027-024-01155-x

Author dataset: https://doi.org/10.57745/YFE6IJ . Original source files under `alpine/` are preserved unchanged. Current repository API metadata labels the licence Etalab 2.0; the supplied author README contains inconsistent licence wording and a CC-BY-NC link. Both original statements are preserved in the downloaded metadata/document. These third-party materials are not relicensed under this repository's code licence. Attribution does not imply author endorsement.

`analyze_alpine.py` and the generated keyed counts, coverage, coefficients and summary are separate analyses. Run `python research/results/independent_pond_20261029/analyze_alpine.py`. Input hashes and access receipts are saved. Main community and environmental CSV checksums match the publisher metadata. Generated method/session tab exports differ from the metadata digest and are not used by this analysis.

Recorded counts are not detection-corrected densities. Nonadult Odonata combine larvae, exuviae and emerging adults; plant richness is not refuge structure. These are same-pond surveys, not acoustic observations or direct predation observations.
