# G15: Does the ABC-accepted acoustic gain exceed generic sign constraints and rate/context sampling?

**Fixed follow-up analysis plan on 2026-11-07 JST, after G14 reported uniform-background improvement but failed both dual-background and unrestricted-interaction gates.** This is **post-hoc source-model predictive specificity**, not new biological/field data, independent prospective confirmation, or a natural trophic mechanism likelihood.

## Core concern

G14's original 794-accepted ABC model average four-sign predictor yielded small geographic heldout strong-call prediction gains under uniform SDMs only. But the original four-sign criterion was constructed with reference to the same observed field-association scientific question; merely selecting source signs could create a directional interaction feature automatically. A successful G14 uniform contrast does not show that **the detailed ABC screening** adds more predictive information than imposing the target signs or selecting the same number of source proposals within synthetic rate/context groups.

## Locked datasets and unchanged observation model

The controlling sources are exactly the original 20,000 genuine 80-year R2 proposal records from eight SHA256-checked source shards, 794 accepted by epsilon=1e-6 four log interaction signs, all 81 attack×recruitment×conversion×development-context counts and all source model four contrasts; G14's unchanged 4,248 NAAMP site/63,180 completed visits/56 geographic blocks/5 predefined folds/two SDM backgrounds and \`G14_original_ABC_source_templates.csv\` with original 794 template. No new source biology or adult-call data. Field predictor is the same four O×S/O×V/S×V/O×S×V rank-suitability/landscape interaction basis; source coefficients mapped using \`[OS−OSV/2, OV−OSV/2, SV−OSV/2, OSV]\`, with \`OS\` etc the original log-F factorial contrasts. Only one nonnegative train-fitted scalar slope is allowed on top of identical \`flex_add\` environmental nuisance, fixed ridge10; same original G14 geographic holdouts. The synthetic source feature lies entirely inside unrestricted \`flex_all\` O/S/V interactions and cannot establish a wild trophic pathway.

## Three fixed sources of comparison

1. **Observed source selection (ABC-794)**: the original mean four source-interaction coefficients of the 794 accepted model proposals; must reproduce the exact archived G14 mean coefficients and, on the source/field replay, its previously measured heldout NLL per background to within 1e-10.
2. **Generic sign-only control (SIGN-ONLY)**: source model sign vector [OS,OV,SV,OSV]=[-1,-1,+1,+1] as the *declared arbitrary unit-contrast* vector, transformed algebraically to the same four field interaction coefficients. Its absolute amplitude is irrelevant to predictor direction because the training model standardizes it and fits its slope. It tests whether just the expected four signs are sufficient to predict calls. This is a toy sign encoding, not a biological model, not a fitted source posterior.
3. **Rate/context-conditioned accepted-label exchangeability control**: for each original 81 rate×context cell, sample without replacement exactly the observed number of accepted proposals \`k_h\` from the \`n_h\` original proposals. For each resampled selection, average the original four source-interaction coefficients exactly as in ABC-794. Use **199 frozen null selections, seed 20261108**, without field-response selection. The null preserves the entire synthetic rate/development composition of ABC-794 and varies only which structures/proposals were accepted. Each template gets exactly 794 original source rows. All 199 fixed null templates and their source digests are archived before or during first null fit. Because sign acceptance is not imposed under this null, a difference may be caused by the sign target itself, rather than unique trophic model selection.

## Fixed ecological prediction and estimands

For each of the 199 null and 2 observed/control templates, each of the 2 SDM backgrounds and 5 original geographic folds, fit \`constrained_train_predict\` from the original G5/G14 pipeline, with identical nuisance inputs and ridge10. The same two environmental baselines \`flex_add\` and \`flex_all\` from G14 are reused from original SHA-verified G14 predictions; no baseline retuning. Do not select favorable nulls or outcomes. Score all 4,248 unique heldout sites, using original n completed visits and k strong-call events. Archive the 56-block loss summaries, per-fold source slopes, template coefficients, original parameter/field source hashes, and complete 199 null wins/losses; if full site outputs are too large, retain a replayable SHA-canonical code and a deterministic 1-in-10 subset of null template site predictions for independent spot checks.

**Primary null-adjusted gain metric:** for each SDM background, \`d_null = (NLL_null − NLL_ABC_794)/63180\` (positive means ABC is better), and \`d_sign = (NLL_SIGN_ONLY − NLL_ABC_794)/63180\`. The empirical source-randomization upper-tail p for ABC outperforming null = \`(1 + #{null NLL <= ABC NLL}) / 200\` (small p means ABC performs better than the selection-without-structure null). Report the full 199-null distribution, mean, median and 2.5–97.5% range, **not** a falsely small p when all constrained slopes are zero. Report the exact signed main effects for uniform and target-group, with no averaging of the two backgrounds as if independent.

**Decisions locked**: a specifically informative ABC source rather than a generic four-sign hypothesis requires ABC-794 to beat the SIGN-ONLY control AND an upper-tail empirical p ≤0.05 against 199 conditional-null templates in **both** SDM backgrounds. Additionally, to be called robust ecological prediction, G14's two background and unrestricted-interaction gates must still pass; they did not, so G15 cannot retroactively establish wild mechanism identification. A more modest positive result can be described only as *exploratory within-background source-shape selectivity*, not field calibration. If the ABC template is not superior to sign-only, refrain from claiming ABC parameter magnitudes carry specific predictive value.

**Numerical validation:** frozen original source SHA and original 81 stratum counts; all 199 nulls with source sample size 794 each; no field leakage in folds; G14 original source-template and NLL replay; exact same sites/calls/fold assignments; independent NLL recomputation of all null 56-block totals; no hidden cancellations of zero coefficients or optimizer failures. Original R1/G5/G7 negative field validation and G8/G11 positive synthetic structural generality remain unchanged.
