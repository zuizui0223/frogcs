# G12 — ABC型POMの機構識別力・事前分布・採択尺度の依存性を原本20,000提案で検証

**2026-11-07、元の80年ABC-POM 20,000提案の原本8シャードをSHA256で照合し、9事前分布・7閾値を独立再計算して完了。** [事前に固定したG12仕様](G12_ABC_POM_PRIOR_IDENTIFIABILITY_PROTOCOL_2026-11-07.md)／[元の20,000件の実行](https://github.com/zuizui0223/frogcs/actions/runs/41262102436)／[元のR2の独立ソース監査](https://github.com/zuizui0223/frogcs/actions/runs/41390511365)／[G12全件監査](https://github.com/zuizui0223/frogcs/actions/runs/42370722253)。

## 1. まず、これは「野外の事後確率を推定するABC」ではない

元のR2は、**3,600個の元の合法モデルID×3発育条件×仮想率・攪乱変数**から20,000提案を事前に一様抽出し、元の生物カーネルを**80年間**動かしてカエル水中個体群量の**4つの対数交互作用符号**（OS負・OV負・SV正・OSV正、ε=10⁻⁶）が合う提案を採択する**rejection ABC-style POM screen**である。保存データから採択**794/20,000（3.970%）**、合成の最低生残5%も満たす採択**426/20,000（2.130%）**、採択した**異なるcanonical model IDが647**だったことを再検証した。元提案20,000件で実際に出現した異なるモデルIDは3,582。

**重要：** 「647」はモデル由来の4符号を作れる構造の数であり、北米のNAAMP強発声に対する尤度で重み付けされた実世界のABC事後支持モデルの数ではない。元の機構カタログは生態学的に均等な自然現象の分布でもない。

## 2. 9つの代替事前分布：採択率は1.09〜6.85%へ変わる

G12は、同じ20,000提案の**仮想率軸への重み付けだけを変更**し、モデル出力・採択の成否を変えなかった。各率軸は3水準で、原priorは(1/3,1/3,1/3)。弱い攻撃重視=(0.60,0.30,0.10)、強い攻撃重視=(0.10,0.30,0.60)、高い加入・速い成熟変換は各々高水準を重視する。同じ名の逆条件は低水準を重視する。単独軸の変更では他軸は元の一様prior、jointは3軸同時に変更。

| 合成事前分布 | 20,000原提案の重要度再重み付け採択率 | 採択重みのKish ESS | Shannon有効モデル種類数 |
|---|---:|---:|---:|
| **元の一様 prior** | **3.970%** | 794.0 | 604.8 |
| 弱い捕食を重視 | **5.059%** | 648.2 | 534.3 |
| 強い捕食を重視 | **2.953%** | 506.8 | 482.3 |
| 高い加入を重視 | **5.149%** | 667.6 | 552.4 |
| 低い加入を重視 | **2.787%** | 518.4 | 492.9 |
| 速い成熟変換を重視 | **4.896%** | 650.1 | 549.6 |
| 遅い成熟変換を重視 | **3.020%** | 529.7 | 482.8 |
| 弱い捕食＋高い加入＋速い変換 | **6.847%** | 481.9 | 480.9 |
| 強い捕食＋低い加入＋遅い変換 | **1.091%** | 381.1 | 428.8 |

※これらの重みは**実世界の推定率でも実測データに基づく事後確率でもない**。あくまで相互作用パターンに着想を得た合成モデルのprior predictive acceptance。全9条件の採択値は、**元の保存済み27率セルの提案数・採択数だけから別実装で再計算し、元20,000行の重要度再重み付けと一致した**。全9条件は重みが正なので、採択された元の647モデルIDは共通するが、有効モデル多様性は変化する。

**肯定的に言えること：** 弱い捕食・高い加入・速い成熟変換側では符号を作る条件が増える傾向があり、同じ元20,000件でも選好する率分布に応じて成立しやすさが変化する。**同時に示すべき弱み：** 成立率はpriorの設定で大きく変わり、機構候補の唯一性は得られない。

## 3. 機構の識別力：647構造が残り、採択重みは一つに集中しない

元priorにおける採択794件は647種類のcanonicalモデルIDに広がり、Shannon entropyの有効モデル数は**604.8**、Simpsonの有効モデル数は**555.0**だった。最も重い10モデルの合計寄与は**3.90%**、50モデルの合計寄与でも**15.49%**しかない。これはモデル符号だけでは特定の構造へ収束しない**equifinality（等結果性）**を支持する。

事前に全列を列挙した構造/条件の受理濃縮表をみると、例えば元priorで\`support_DF=1\`（植生によるD→F捕食支援）は元提案の**50.36%**に対し、採択集合では**67.38%**に現れた（採択/元prior比**1.34**）。代替率priorを変えても採択集合内の\`support_DF=1\`割合は**64.48〜71.58%**だった。しかしこれは**元カタログ上の条件付き相関であり、野外の捕食機構の必須性・十分性や生物学的因果を識別したものではない**。別のR2/G8/G11の植生二機能介入はこの単純なモデル間相関とは別に報告する。

## 4. εを変えると採択集合は減少する

元の4方向は**logカエル量の交互作用の符号**であり、その大きさをどこまで要求するかはモデル内の採択尺度の一部。元の4つの連続値を使い、すべて同じ厳密符号判定でεだけを変更した。

| ε（log尺度） | 採択提案／20,000 | 採択異なるモデルID | 人工5%生残も満たす採択 |
|---:|---:|---:|---:|
| 0 | 830 | 667 | 426 |
| **0.000001（元基準）** | **794** | **647** | **426** |
| 0.0001 | 733 | 601 | 384 |
| 0.001 | 538 | 453 | 245 |
| **0.01** | **267** | **239** | **99** |
| **0.05** | **71** | **66** | **9** |
| 0.1 | 8 | 7 | 0 |

強い符号ほど候補が絞られる一方、ε=0.1では20,000提案中**8提案**しか残らない。これは実際の野外相関強度が0.1に相当することを意味しない。**εを結果に合わせて選ぶことは禁止**し、元解析の推論はε=10⁻⁶のまま保つ。

さらに、同じε=10⁻⁶でも**生のカエル量**で符号を評価すると採択は**584件（498種類のモデルID）**だった。元の**対数尺度の794件とは共通462件、対数尺度だけ332件、生尺度だけ122件**だった。生と対数では量の意味が異なるので、都合の良いほうを「本物のPOM」だと選択しない。

## 5. 論文の採用可能な主張・採用できない主張

採用可能な最も厳密な表現：

> **A model-native, rejection ABC-style screen identified hundreds of structurally distinct ways to generate the four idealized interaction signs. Their apparent frequency was sensitive to assumed ecological-rate priors, the minimum accepted effect threshold, and response scale. Separately, independent held-out structures reproduced the mismatch between pattern generation and frog demographic benefit.**

採用してはいけない表現：観測した北米のコーラスに対する機構のBayesian posterior / posterior probability、647構造を野外の観測によって絞り込んだ、事前分布を較正した、εを野外の相関強度に変換できた、G11の構造独立性が自然の機構の実証である、という主張。

**研究の主線は変えない。** R1の野外相関がモデル構築の動機、R2/G12がモデル内POMとABC型機構探索の限界・成立条件、G8/G11が独立構造でのパターン生成と個体群量の乖離、G9/G10が同条件での解釈の境界、P1が加入と水中期間の独立操作である。G5/G7の地域外予測ゲート未達も必ず併記する。
