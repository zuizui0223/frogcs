# frogcs 総合監査：植生保護の相手によって4符号とカエル個体群の帰結が乖離する

**2026-11-01｜PR #160への既存結果の独立再集計＋PR #159との非混同照合。野外で捕食機構を同定した結果ではない。**

> **追補（元の生物結果は不変更）：** [原発育条件での生残5%フィルターと捕食経路の感度解析](INTEGRATED_MAIN3600_SURVIVAL_FLOOR_EDGE_SENSITIVITY_2026-11-01.md) が [GitHub Actions #41298704170](https://github.com/zuizui0223/frogcs/actions/runs/41298704170) で成功。元96組のうち50組に絞ると、カエル保護の4符号成立率への寄与は3発育条件とも正に変わり、全96組での「+,+,−」という点推定の順序は頑健ではない。有尾類をヤゴから保護する介入については**発育条件1**でカエル量への負の効果と4符号への正の寄与が生残条件後にも共存した。発育条件2の成立率の正方向は生残フィルター後に区間が0をまたぐ。元のPR146の別実験での肯定結果は撤回しない。\n\n## 研究の現時点の主張

植生の役割を一律に「カエルを守ること」とみなすのでは不十分である。元の同一食物網・同じ生物学的率で機能を操作すると、**カエルを有尾類から守る植生は水生カエル量を増やす**一方、**有尾類をヤゴから守る植生はカエル量を減らしながら、特定の発育条件では4符号の再現性を高める**ことがある。

つまり、(1) モデル内で個体群を増やすこと、(2) OS−・OV−・SV+・OSV+ の交互作用符号を生成すること、(3) 有限個体数の80年占有・再占有を維持することは、**別々の生態学的帰結**である。これらを同じ「モデルが実測を説明した」という成功指標に統合しない。

## 新しい独立の原ID層別再標本化

**固定元データ:** [PR #160 80年source SUCCESS #41262102436](https://github.com/zuizui0223/frogcs/actions/runs/41262102436) の `integrated-234-paired-stage-vegetation/posterior_paired_plant_stage.csv` 576行。独立単位は96個の元 `source_draw_id`。同一IDは3発育条件×2植物機能へ対応付け、**発育条件ごとの独立96本**と誤認しない。96の元条件は0/1/2で各32抽出。各選択の重みは `(317,265,212)/794/32`。元IDを同じ条件の32組から復元抽出する**層別20,000回bootstrap**（seed 20261101）を行い、カエル水生コホートの平均 `log(F_B)` と4符号完全成立のON−OFFを再評価した。

**表の95%区間は、選択された仮想元モデル源に対するMonte Carlo／抽出誤差のみで、野外生物学的な信頼区間・因果効果の不確実性ではない。**

**新しい積極的な識別結果:** main context 2では、植生によって有尾類をヤゴから保護するとモデル内カエル量は減る一方、4符号パターンの成立率は上がる。**パターンの生成可能性と個体群への純利益を同一視できない**ことを、同一モデル・同一率の介入対比較で直接示す。

元96モデルのうち19はヤゴ→有尾類捕食経路 `edge_DS=0` であるため、`cover_DS` 切替は完全に無効（Δ0）。作用し得る `edge_DS=1` の77モデルに限った記述的感度では、context 2の重み付きΔlog(F_B)は−0.01752、4符号差は+9.73ポイント。77組は事前指定の機構的作動条件だが、96組の主比較を置換するものではない。

## 元mainおよびPR #146 / #159 との整合

- 元mainの候補 #1479/#1455 は植生によるF保護、D→S捕食、litterの密度依存的D→F捕食型を含み、#1455でも指定3方向が成立した。PR #160の全3,600構造の20,000率比較で **S→D OFF の成功が272件**あるため、その候補だけにS→Dの必要性を一般化できないことが明確になった。
- PR #146は**別の3つの発育条件・別の64率と主尺度log(F_B)**で、`litter` と `cover_SF` の4符号成立率への寄与が正負逆転する明瞭なモデル内結果を得ている。今回のPR #160は主元カタログの3条件と成功抽出96組を使っており、前者の数値的直接反復ではない。PR #146の肯定結果は撤回せず、実験の定義差を明記する。
- PR #159 はS/Dの加入日、成長・水中期間が異なる拡張源を用い、外部移入OFFの8パッチ有限N。SF保護の年80占有への平均増分は original q3/+0.125, q12/+0.668、D-first q3/+0.035, q12/+0.408、S-first q3/+0.025, q12/+0.525だった。PR160の `log(F_B)` への介入効果と**方向的には整合**するが、同じ元ステージ・同じ母集団・同じ指標に対する複製値ではない。
- PR #160の年80有限Nでは、S→F捕食による「移動ON−OFFの調節効果」の重み付き平均は q3 −0.009 [−0.264,+0.240] パッチ、q12 −0.012 [−0.069,+0.041]。**一般的な分散救済機構の再現とは扱わない**。q12は8/8に近い天井効果が強い。

## 野外実測との境界

北米4,248地点・28分類群の高／低有尾類適合度によるヤゴ適合度―カエル強発声相関差（uniform −0.385、target-group −0.179）は**観測的肯定結果**。しかしO/Sは適合度、Vは3km景観植生代理、Fは成体強発声頻度である。一方モデルのS/Dは幼生供給、Vは機構切替、F_Bは水生コホート。**野外の直接・間接捕食を証明していない**。PR #158の6実測統計量への同じ元生物率のサイト写像でもuniform 0/768、target-group 7/768、両方に一致する単一構造なし。旧132固定表面も両背景で完全適合0。これは機構の可能性を否定するものではなく、現段階の観測橋渡しと候補では野外原因を識別できないという限界である。
