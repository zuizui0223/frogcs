# 共通季節・年次カーネルからの空間拡張：PR #146 → PR #147 の接続ゲート（2026-10-31）

## 現在地と判定原則

- **野外の根拠（main）**：NAAMP 4,248地点のOS− / OV− / SV+ / OSV+ は、トンボ類・有尾類のSDM環境適合度、3 km景観植生、成体強発声の条件付き相関。4方向とも2背景で点推定は一致するが、target-groupのSV・OSV区間は0を跨ぐ。
- **機構の根拠（#146）**：120日の実モデル季節捕食と80年遅延加入の合成モデル内4方向。植生が何を保護するか × 発生順序で4方向生成確率の寄与が正負反転する。64共通親256 rate IDを用いた108 canonicalモデル事前比較が直近の正式な科学結果。野外で真の植生・捕食機構を同定したものではない。
- **空間の根拠（#147）**：別の7段階・20年・8パッチ確率的ABMでは、移動と再占有があっても年20占有を維持できない場合がある。ABMのstage・出生・消失率は#146の年次コホートモデルに校正されていない。

**今回の主作業：#146のカーネルを本当に使ったまま、年次コホートの空間再配分を追加して、同じ4符号と場所間の相対集中が共存できるか検査する。** #147を#146の真の個体群モデルとして無言で置き換えない。

## 1. 同一性ゲート：結果を読む前に必須

research/scripts/spatial_cohort_80y_bridge.py は既存の stage_network_extension_20261029.simulate を直接呼び、元の年次 survival*B + local_recruits + immigration、F遅延2/3年・S2年・D1年、K、季節内の餌処理・サイズ依存・逆転捕食のパラメータをそのまま保持する。

**homogeneous・移動OFF・8パッチ**は、同じモデルnative 2×2×2頂点の元 annual_recurrence_plant の F_B／F_fraction／F_B_sd に、それぞれ絶対誤差 1e−8／1e−8／1e−7 以内で一致しなければ先に進まない。全パッチ同一なら、輸送ONでも局所パッチの値が変わらないことを負対照とする。輸送演算子は非負・環状隣接移動・総量保存をテストする。

## 2. 空間機構：何を動かしているのか

8つの合成環状パッチ、近傍2パッチへの対称年次移動。2×2×2の元の植生0/1頂点を、空間比較ではそれぞれ **[0.0, 0.4]／[0.6, 1.0]** の交互植生モザイクに操作する。S/D供給は元の低0.25／高2.0を各パッチへ同じように与える。これは野外の距離・植生や水域連結性の測定ではない。

移動は次の4条件を同じ元率drawで対比較する。

1. off：年次輸送なし
2. recruits：年次成熟待ち後の局所加入項だけを輸送
3. carryover：年末更新の生残残存項だけを輸送
4. both：二つを輸送

輸送率は（たとえば）毎年15%が隣の2パッチへ合計移る**年次分率**。#147の個体当たりモデル年拡散係数0.05/0.22とは次元・機構が異なり、一致させていない。新しく設定した移動経路は主に数理的に検証可能な最小ブリッジであり、幼生・成体の実測分散を識別するものではない。

## 3. 事前固定の小規模比較（結果を見てからクラスを変更しない）

- 元の3発生順序、基準餌処理、危険誘導避難OFF
- 元の12合法植生役割から **SF1_DF0_DS0_L1、SF0_DF0_DS1_L0、SF1_DF0_DS1_L0** の3つ（旧基準・新しく最上位となった役割・二重保護）。いずれもmain合法
- 元256率drawの事前固定 **ID 0,4,8,12** から最大4個、逆転捕食ON/OFFをともに保持
- 元の8頂点のF_Bを**パッチ平均してから**logを取り、4符号OS− OV− SV+ OSV+を判定（raw F_Bを別尺度で保存）
- パッチ内のF_BのCVとeffective patches = (sum B)^2 / sum(B^2)、各頂点のマッチしたmovement−off差を同一drawで保存。これは密度の相対集中であり、音響活動の空間集中や再定着数ではない
- 同じ入力でhomogeneous/source replayに失敗したら4符号・分散結果を無効とする

先に4年のsmokeテスト、通過後に80年の同じ条件を検査する。80年の読み出し窓は最後の20年。4年のsmoke結果を生態学的な結論として引用しない。

## 4. 構造的に不可能な比較と、その解消条件

元#146の年次式には**正の外部immigrant項**が毎年入り、密度は連続変数である。閉鎖8パッチ個体ABMの **N=0→N>0** という再占有とは同じ測度ではない。任意の密度閾値を設定して「局所絶滅」と呼ぶことを禁止する。

野外の発声・SDM適合度・景観植生も、F_B・個体の捕食者密度・パッチ植生機能とは同じ測定物ではない。**同じF_Bの4符号、空間濃淡、音声集中、親子系譜を単一の野外ABC尤度として合算しない**。

次の接続ゲートは、元のseasonal hazardとmaturation/annual recruitmentの期待値を保った**有限個体モデル**を新たに定義し、外部流入の有無を因子として固定し、年末のN=0、再占有後の持続・出生の分母と右打切りを#147と一致させること。独立に校正された個体密度・捕食率・発声観測過程がない限り、野外因果を主張しない。
