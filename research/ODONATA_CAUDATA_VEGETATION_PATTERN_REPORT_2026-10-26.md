# トンボ類の負の相関に、有尾類と植生を加える

2026-10-26。目的は相関の洗い出し。反復や普遍性を成果の前提にしない。4,248音響地点を用い、同じデータ内で関係がどう変わるかを探索した。

## 最初の負の相関から、条件付きの関係へ

全地点でのトンボ類の平均適合度と強い鳴き声頻度の相関は、均一背景でρ−0.095。この関係を有尾類の平均適合度の低・中・高（全対象の三分位、同値は分割しない）に分けて調べた。強い鳴き声頻度は、少なくとも1種のカエルがCallingIndex≥2だった訪問の割合。トンボ類適合度は成虫も含む種の記録から推定しており、ヤゴ密度の実測ではない。

### 池で繁殖する有尾類で分けた結果

|---|---|---:|---:|
| 均一 | 低 | 1,417 | +0.101［−0.008,+0.202］ |
| 均一 | 中 | 1,419 | −0.077［−0.163,+0.012］ |
| 均一 | 高 | 1,412 | **−0.284［−0.368,−0.201］** |
| 同群記録 | 低 | 1,420 | −0.004［−0.112,+0.100］ |
| 同群記録 | 中 | 1,412 | −0.123［−0.229,−0.014］ |
| 同群記録 | 高 | 1,416 | **−0.183［−0.298,−0.077］** |

高適合度群−低適合度群の相関差は、均一背景で−0.385［−0.509,−0.240］、同群記録背景で−0.179［−0.328,−0.029］。二つの背景は同じ資料の感度比較である。

**有尾類の適合度が高い地点で、トンボ類適合度と鳴き声頻度の負の相関が大きい**という、次に調べる価値のある配置が得られた。低適合度群での正の点推定は区間が0を含むため、「正から負への逆転が確定」とまではしない。

全有尾類でも、高適合度群は両背景でρ約−0.215。低適合度群は均一背景+0.093、同群記録背景−0.071だった。池繁殖群に限定した結果と全有尾類の結果を混同しない。

## 地点配置として何が見えるか

均一背景の池繁殖有尾類が高適合度の群では、トンボ類適合度が低・中・高の順に、地点平均の強い鳴き声割合が0.695、0.535、0.531だった。有尾類適合度が低い群では0.556、0.580、0.627。同群記録背景でも、有尾類高群では0.687、0.607、0.549、低群では0.533、0.545、0.588。

これは三分位セルの記述平均であり、セルを移動させた因果効果ではない。図には全36セルの地点数を併記した。両群の適合度自体にも正の相関があり、池繁殖群との相関は均一背景0.233、同群記録背景0.414。共有環境と地理的な配置もこの関係の候補に残る。

同じルート内の順位関係では、池繁殖有尾類高群の相関は均一背景−0.086［−0.143,−0.029］、同群記録背景−0.053［−0.111,+0.006］。全域の配置と局所の関係の大きさを分けて記録する。全域の結果を取り消す判定ではない。

三分位だけに依存しない補助解析として、標準化した順位の `鳴き声 ~ トンボ + 有尾類 + トンボ×有尾類` も実行。池繁殖群の交互作用係数は均一背景−0.115［−0.169,−0.059］、同群記録背景−0.057［−0.117,+0.001］。点推定の方向は揃うが、区間や局所結果には背景依存性がある。

## 植生は、このネットワークで何を変えるか

問いは「植生と鳴き声が正に相関するか」ではなく、**植生条件によって、トンボ類・有尾類のニッチと鳴き声の関係がどう変わるか**である。

仮説として区別する役割は、(1) 隠れ場による遭遇・捕食効率の変化、(2) 産卵や幼生利用の基質、(3) 羽化基質、(4) 両群を同じ場所へ集める構造。役割によって直接・間接経路は異なり、植生の単独の相関がゼロでも矛盾しない。現時点ではそれぞれを観測済みとは扱わない。

既存のEarthEnv冠水植生被覆>0を使い、全下位項を含む `鳴き声 ~ トンボ + 有尾類 + 植生 + トンボ×有尾類 + トンボ×植生 + 有尾類×植生 + トンボ×有尾類×植生` の順位回帰を探索した。背景2種×有尾類2群×全域／ルート内をすべて保存した。

冠水植生>0は46地点・27ルート、0は4,202地点。三者項の全域係数は、池繁殖群で均一背景−0.644［−8.911,+0.172］、同群記録背景−1.123［−8.126,+3.270］。全8設定の三者項区間は0を含み、現状の指標では関係を強めるか緩めるかを絞れない。これを植生の機能がないという結論に置き換えない。

この変数は粗い土地被覆であり、池の水草構造や利用行動を直接測っていない。対象地点を深掘りする際には、植生を一括の「量」にせず、水中の隠れ場と水上の羽化・産卵基質を分ける。メチル化eDNAなどによる段階・繁殖状態の観測も、この条件付きの関係を追うために接続する。

## 現時点の仮説の接続

得られたのは「有尾類にも適する環境で、トンボ類適合度と強い鳴き声がより負に関連する」という相関。単純な第三者による救済だけを選んで説明せず、共有環境、二群の複合的な制約、段階のずれ、植生による経路の変化を候補として並べる。既存の三者シミュレーションは仮定した経路がこのパターンを作りうるかを考える補助であり、この実測相関へ適合済みではない。

## 方法・検証・保存先

- 事前に固定した比較：既存の4,248地点、2背景、全有尾類／池繁殖群、適合度三分位、1,000回のルートbootstrap。結果を見て有利な区分へ変更していない。
- 三分位の境界は元の対象で固定しbootstrapでも維持。相関と連続順位回帰の順位は各再標本で再計算する。区間はSDMを固定した条件付き区間で、多重比較調整はしていない。
- `research/scripts/naamp_odonata_caudata_associations.py`：全層別相関、相関差、連続交互作用、36セルの平均・分母、図。
- `research/scripts/naamp_vegetation_network_associations.py`：植生による関係変化、全下位項、観測範囲、階数不足時の欠測保持。
- `research/scripts/test_naamp_network_associations.py`：同値を分割しない区分、ルート内推定と明示的固定効果回帰の一致、植生対比がない場合をゼロ効果にしない処理の3テストが成功。
- 全数値：`research/results/naamp_odonata_caudata_associations_20261026/`。入力hash・乱数seed・観測範囲をJSONに記録。

これは既存結果を受けた探索解析であり、独立した確認研究ではない。相関の洗い出しとして提示し、その価値を普遍性の未確認によって否定しない。
