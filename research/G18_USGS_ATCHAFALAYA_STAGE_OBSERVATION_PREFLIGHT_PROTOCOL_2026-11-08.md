# G18 — Independent USGS acoustic-to-larval observation bridge: source-only eligibility gate

**Fixed 2026-11-08, before inspecting USGS response records or choosing species.** Origin: Glorioso, B. M., and Waddle, H. (2025), *Data from time-constrained visual encounter surveys and acoustic surveys for amphibians and reptiles in the Atchafalaya Basin conducted from 2008 through 2016*, USGS data release DOI **10.5066/P9T71JCO** (CC0; USGS ScienceBase item **5eb5880c82ce25b5135ae784**). Source period **2008-02-19 to 2016-07-13**. Official USGS documentation states the dataset includes both concurrent vocalization observations and tadpole/larval presence, with site, sample and observation records.

**Goal:** first determine whether an *external-to-the-original-NAAMP-dataset* field observation source can quantify a same-taxon, same-site, strictly earlier adult calling → later recorded tadpole/larva link. This is independent source acquisition, not the original G17b post-hoc SDM background tuning. It does NOT measure adult-call → individual survival, food-web Odonata/Caudata densities, simulated 4-factor sign patterns, or natural predator feeding effects.

## Phase A: response-blind original source access and schema gate

1. Attempt public ScienceBase original item sbJSON via official item REST URL \`https://www.sciencebase.gov/catalog/item/5eb5880c82ce25b5135ae784?format=json\`; optionally official USGS metadata/direct file links if first source is unavailable. Persist exact URL, HTTP status, Date/ETag headers, source item title, original item ID, file manifests, size and checksums when supplied. **No substitute from a different DOI or a flattened GBIF occurrence file.** Maximum metadata response 5 MB and original file 50 MB each. Distinguish \`ACCESS_BLOCKED\`, \`METADATA_READY\`, \`SCHEMA_READY\` and \`DATA_VALIDATED\`.
2. Before opening species responses, record only each original file's byte SHA256, original filename, declared license/DOI, size, CSV column names (including BOM/encoding), original row count and non-response identifier/date/method missingness. Do **not** publish raw personal names or precise unpublished habitat coordinates; source publication is CC0 but identify potential sensitive wildlife locations and limit repository outputs to aggregate results when necessary.
3. The required data model must allow matching **independent original sample ID** ↔ **stable site ID** ↔ **visit/date** ↔ **taxon** with a stated **adult-call observation** and a separate **tadpole/larva observation**, and must document survey opportunities and truly explicit non-detections. A blank observation row or absence of a taxon from a list must NEVER be converted to \`0\` without a documented complete check/effort for the corresponding taxon and sampling method.
4. Declared eligibility outcomes:
   - \`FULL_STAGE_OBSERVATION_READY\`: same-taxon, same-site adult vocalization and independent larval stage records, stable dates, usable observation effort/explicit negatives for both, and at least 25 independent sites and 50 matched taxon×site-year opportunities, with ≥10 each observed larval positives and explicit negatives.
   - \`PAIRED_POSITIVES_ONLY\`: same source site/taxon/timing observable but no explicit well-defined negative opportunities; only the **descriptive fraction of co-reported records** can be calculated, not predictive specificity/absence.
   - \`UNPAIRED_STAGES\`: only across-site or unrelated taxon observations; no within-site stage bridge.
   - \`ACCESS_BLOCKED_OR_SCHEMA_UNKNOWN\`: source API/download not available; do not infer ecological non-replication or invent counts.
5. If full stage observation eligible, freeze exact joint source-row/effort unit before reading outcome cells and **before** fitting models. The original NAAMP source is never joined to the USGS data by nearest coordinates, and no original NAAMP-trained predictor is retrospectively changed.

## Phase B: guarded future original-outcome analysis (only after Phase A)

- Define prior call as a recorded adult vocalization **strictly earlier in date** than subsequent larval survey of the **same taxon and same identifiable source site**, within the same source year. Same-day acoustic/larval co-observation is a **separate descriptive cross-method detection analysis**, not temporal stage transfer.
- Prefer a true site-level heldout prediction (all original observations for one site in one fold), with a separate forward-time 2014–2016 check if explicit opportunities and both response classes are sufficient. A future-year failure is an informative boundary, not grounds to change dates. If no stable temporal sample meets ≥25 independent sites and ≥50 source taxon×site-year opportunities, classify predictive bridge **not estimable** and report full support.
- Compare a simple source-year, survey month/DOY, survey method/effort baseline to the same baseline + a **single prior adult-call indicator**, if the fields exist. Heldout Brier/log NLL evaluated at site/year granularity. Do not fit downstream outcomes from survey rows without complete detectability metadata or stage matching. A positive prior-call coefficient may reflect breeding phenology/occupancy shared causes, not a measured adult-to-larval survival probability.
- Independent USGS amphibian/tadpole observations cannot **causally identify** the simulated frog–odonate–salamander–vegetation food-web generator without predator density/stage, real pond habitat or a randomized control. This boundary remains even if calls forecast larval observations.
