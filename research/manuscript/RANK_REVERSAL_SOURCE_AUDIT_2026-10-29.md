# 応答の順位化で三者交互作用が反転する理由：保存済みモデルの監査

対象は `final_mechanism_20261027/winner_rank_cells.csv.gz` の model 1479・block 13・21×21×2 = 882 条件。機構・パラメータ・出力を変更せず、応答の変換だけを変更した。これは新たな機構探索でも観測への再校正でもない。

## 結論

**順位化による D×S×V の反転は、捕食の方向が逆転したのではなく、応答の距離の測り方が変わったためである。ただし、原尺度でも D×S は弱く、順位化だけを直せばマクロとの機構的一致が確立するわけではない。**

順位化は大小関係を保存するが、減少量の大小や差の差を保存しない。植生がモデル応答 F_B を大きく上方へ移動させるため、低植生と高植生では同じ個体群量の差が横切る順位数が異なる。ここで F_B はモデル内の水生段階の個体群量であり、観測された鳴き声ではない。

## 四隅で直接確認

D・S の低値は 0.25、高値は 2。順位は **全 882 条件を一緒に** 順位化した百分位（0–1）である。D 効果は高 D − 低 D、差の差は「高 S の D 効果 − 低 S の D 効果」。

|植生|尺度|低 S での D 効果|高 S での D 効果|差の差|
|---|---|---:|---:|---:|
|低|F_B|−0.039798|−0.063263|−0.023465|
|高|F_B|−0.100369|−0.108720|−0.008352|
|低|全体の順位百分位|−0.102041|−0.069161|+0.032880|
|高|全体の順位百分位|−0.165533|−0.265306|−0.099773|

原尺度では、低植生で有尾類 S が多いほど D による減少量が大きい。この増幅は高植生では小さい（差の差の植生間差 +0.015113）。一方、低植生・高 S の応答は分布の下端にあり、大きな F_B 減少でも通過する順位数が少ない。そのため順位では低植生の差の差が正になり、高植生では負となる（植生間差 −0.132653）。**四つすべての D 効果は、どちらの尺度でも負のまま**である。

例えば低植生・低 S は F_B 2.230817→2.191019（順位 0.552721→0.450680）、低植生・高 S は 2.003614→1.940351（順位 0.069728→0.000567）。後者の個体群減少量は大きいが、順位の下落幅は小さい。これは生残がゼロ近くに潰れる生物学的な床効果ではなく、**経験分布上の順位間隔**の問題である。高植生では 2.435741→2.335372 と 2.282625→2.173905 が、それぞれ異なる密度の分布領域を横切る。

低植生 F_B の範囲は 1.940351–2.230817、平均 2.094178、高植生では 2.173905–2.435741、平均 2.306741。植生による大きな主効果が、全体順位での比較を左右する。

## 882 点すべてを用いた同一回帰式での再現

説明変数 D、S、V を全体で順位標準化し、切片 + D + S + V + DS + DV + SV + DSV を OLS で推定。応答だけを原値標準化または順位標準化した。

|応答|DS|DSV|低植生での DS|高植生での DS|主効果の分散寄与|
|---|---:|---:|---:|---:|---:|
|原値標準化|−0.011593|+0.005489|−0.017081|−0.006104|98.6082%|
|順位標準化|−0.010382|−0.010418|+0.000036|−0.020800|98.9682%|

DS の分散寄与は原値でも 0.0134%、順位では 0.0108%。したがって「順位化がすべての不一致の原因」とは結論できない。三者交互作用の符号は尺度依存だが、強い主効果に比べて DS が弱いことは双方に共通する。分散寄与はこの均衡・直交格子内の応答分散についての計算であり、実際の地点集団における説明率ではない。

数学的には、連続的な単調変換 g を考えると

`∂²g(F)/∂D∂S = g′(F) F_DS + g″(F) F_D F_S`

であり、g′ > 0 でも第 2 項が加わるため交互作用の符号は保存されない。経験順位そのものは階段関数なので、この微分式は直観を説明する近似であり、今回の直接証拠は上の有限差分と保存点の再回帰である。正のアフィン変換である通常の標準化だけなら、この反転は起こらない。

## マクロと「同じ解析」にする際の限界

- 変換、中心化・標準化、交互作用の組み立て、回帰式、重みを揃えることはできる。順位は必ず積を作る前に各変数へ適用し、同順位の処理も統一する。
- マクロの現在の植生変数は 3 km 内の flooded vegetation の連続値（ゼロが多数）。モデルの V は 0/1。マクロも V > 0 に二値化する比較は共通の対比になるが、元の連続植生解析とは別の推定対象である。
- 均等なモデル格子と実地点の D/S/V 同時分布は異なる。順位と回帰射影は分布依存なので、重み付けによる検証は必要。ただし適合度の分位点をモデル投入量へ対応させる操作は診断用の仮定であり、生物学的校正ではない。
- マクロはトンボ・池性有尾類の SDM 適合度と強い鳴き声の頻度、モデルは投入量と水生個体群量。どちらも順位化しても同じ生物学的量にはならない。
- マクロの調査条件・気候・空間調整やルート内解析に対応する変数はモデル格子にない。共通の無調整回帰とマクロの調整済み回帰を別々に示すべきで、両者を完全に同一解析と呼ばない。
- 保存された block 13 は選択済み条件であり、この監査は選択を独立検証に変えるものではない。全 24 条件の支持率やマクロ側の交互作用の不確実性は別に残る。
