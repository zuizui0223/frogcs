# frogcs：S→F捕食は成長・局所加入に依存する分散効果の反転を、固定モデル内で必要かつ十分に生成する

2026-10-31 / Draft PR #153。PR146の120日季節内捕食＋80年遅延加入モデルを変更せず、有限個体確率過程で4方向の捕食経路の削除実験を行い、さらにS→Fのみを残す経路十分性実験を追加した。

## 最新の確定したモデル内結論

**今回選んだ2つの元仮想率背景、個体数尺度q3、外部流入OFF、合成8パッチ、年次移動15%、植物2役割、S成長×D水中期間2×2、各12独立乱数系列という固定モデル内では、有尾類幼生→カエル幼生（S→F）捕食の経路が、有尾類の成長高速化に伴う「分散が年80末のカエル占有を増やす／減らす」を反転させるために必要であり、この経路だけでも反転を生成するのに十分だった。**

必須の限定：S→F経路は野外で測定した捕食率に校正されていない。追加のすべての数値は元モデルの条件に依存する合成モデル内の介入結果であり、世界の湿地に普遍的な必要十分条件を証明したものでも、NAAMPの成体の強発声を生み出す因果機構の検証でもない。

## 2. 捕食経路ネットワークによるS成長依存の分散効果反転

**厳密な4条件の反転の定義**：D水中期間40/60日の両方で、S低成長時には「移動あり−なし」の年80末F占有パッチ差が正、S高成長時には負となる。単位は8合成パッチの整数F>0占有。局所加入高条件は、元仮想率ID12の他7軸を固定してρのみID0値に交換したもので、外部流入OFFなのでρ×conversionという**同一の局所加入合成強度**の変化である。

| 捕食ネットワーク | rate12_base（低局所加入） | rate12_rho0（高局所加入） |
|---|---:|---:|
| 4有効方向全てON | 0/2植物 | **2/2、各12/12seed** |
| **SF（S→F）のみON** | 0/2植物 | **2/2、各12/12seed** |
| SFだけOFF、残り3経路ON | 0/2植物 | **0/2、各0/12seed** |
| DF（D→F）のみOFF | 0/2植物 | 2/2、各12/12seed |
| DS（D→S）のみOFF | 0/2植物 | 2/2、各12/12seed |
| SD（S→D）のみOFF | 0/2植物 | 2/2、各12/12seed |
| **直接捕食4方向すべてOFF** | 0/2植物 | **0/2、各0/12seed** |

S→FだけONで反転が成立し、S→FだけOFFで消失するため、**本固定モデル内の長期占有の反転にはS→Fが必要、他3捕食方向がなくてもS→Fだけで十分**という判定が成立する。一方、加入強度が低いrate12_baseではS→FだけONでも反転せず、局所加入との組合せが必要。

## 3. S→Fの十分性を示す占有差（高加入条件 rate12_rho0）

各数値は「移動あり−なし」における年80末F占有の平均パッチ差。左・右は元の合法植生機能SF0_DF0_DS1_L0／SF1_DF0_DS0_L1の順。

| 成長・期間 | 4方向全部ON | **SFのみON** | **直接捕食全部OFF** |
|---|---:|---:|---:|
| S低成長、D水中40日 | +3.938 / +3.828 | **+4.068 / +3.906** | +1.135 / +0.974 |
| S低成長、D水中60日 | +4.177 / +3.724 | **+4.161 / +3.849** | +1.000 / +1.099 |
| S高成長、D水中40日 | −1.125 / −1.063 | **−0.984 / −0.839** | +0.995 / +0.964 |
| S高成長、D水中60日 | −1.208 / −1.245 | **−0.906 / −1.005** | +0.953 / +1.062 |

S→Fだけを残した場合、移動効果は低S成長で約+4パッチ、高S成長で約−1パッチと符号が明確に逆転した。直接捕食をすべてOFFにした場合、年80末占有への移動は約+1パッチで、**S成長に応じた符号反転はなくなる**。

## 4. 機構的な成長修飾：12seedにおけるMC区間

rate12_rho0でS成長増加が「移動による年80末F占有差」に及ぼしたモデル内主効果：

| 捕食方向 | 植物機能SF0_DF0_DS1_L0 | 植物機能SF1_DF0_DS0_L1 |
|---|---:|---:|
| 4有効経路全部ON | −5.224 [−5.396,−5.052] | −4.930 [−5.083,−4.784] |
| **S→FだけON** | **−5.060 [−5.211,−4.904]** | **−4.799 [−4.982,−4.591]** |
| **S→FだけOFF** | −0.010 [−0.193,+0.164] | −0.094 [−0.229,+0.055] |
| **4有効経路全部OFF** | −0.094 [−0.216,+0.018] | −0.023 [−0.156,+0.102] |

角括弧は12独立乱数seedごとに固定源処理を平均し、9,999回再標本化した**有限合成モデルのMonte Carlo区間**。野外の捕食圧・移動率・繁殖成功の95%信頼区間ではない。

ここでS→F-only条件の植物機能SF0_DF0_DS1_L0は元来D→S捕食からSを保護する役割であるが、D→S経路をOFFにしたため**この植生保護作用自体は無効**になる。従って「2つの異なる植物保護機構が独立に確認された」という主張はしない。検証されたのは2つの元の植物因子設定での数理的反転である。

## 5. 何が成立し、何がまだ残るか

**成立した（モデル内）**：F幼生へのS幼生捕食による体サイズ・捕食機会の変化が、局所加入と分散の長期収支を変えることが可能である。S→Fの単経路切断とSF-only条件で、限定された率背景における反転の必要性と十分性を切り分けた。

**未成立・未検証**：
- 元256 LHSの生物率の幅広い領域での再現。元PR151ではS成長による正→負反転は4生物率のうちID0だけで、今回のID12+ρ(ID0)は別の特定条件である。
- 野外のS→F捕食率、成長率、局所加入、降雨、実際のパッチ連結度や移動確率。未校正q3・移動0.15・人工8パッチに限定される。
- 野外でFの年80末占有が強い成体発声や繁殖成功につながる直接的な観測過程。今回のFは有限のcohort個体群の数であり、NAAMPの発声地点の時系列とは別。
- 再占有後の局所加入が、その再占有個体の子孫であるという親子同定。元の遅延cohortが後年加入する可能性は残る。
- FE（F完成後の羽化D捕食）は今回のD0/S20 subsetでは厳密ゼロだが、PR148第3S先行条件では陽性であり、当該限定条件だけの結論をPR148や独立PR147の7段階ABMへ外挿しない。
