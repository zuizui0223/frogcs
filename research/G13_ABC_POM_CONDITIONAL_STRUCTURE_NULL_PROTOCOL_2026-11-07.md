# G13 — Conditional-null identifiability for the original model-native ABC–POM screen

**Design fixed on 2026-11-07, after R2/G12 aggregate and individual feature enrichment findings were available, but before computing G13 conditional-null permutations.** This is a *post hoc source-audit diagnostic*, NOT a preregistered field or ABC posterior test. No new biological simulations, no field-predator estimation, no posterior probabilities for natural pond processes.

## Scientific test
The original synthetic ABC-like R2 screen accepted 794/20,000 structure×nuisance proposals (647 distinct canonical model IDs), under the model's idealized OS−/OV−/SV+/OSV+ log aquatic frog cohort sign criterion (eps=1e−6). R2/G12 already showed that acceptance is strongly dependent on synthetic ecological rates and developmental context. **How much does accepting four signs constrain the model's *structural* component, after preserving exactly that rate/context dependency?**

Check the 27-cell original accepted counts against frozen G12/R2 authoritative table. Fail closed if anything differs.

## Exchangeability null
Use all **81 exact rate×developmental-context strata**: attack [.5,1.5,3] × local recruitment [.25,.5,.75] × conversion [2,4,8] × context [0,1,2]. Within each stratum retain the **observed** N_h proposal count and the **observed** K_h accepted count. Under the conditional null, *which proposal's structural catalogue ID/feature label* receives the acceptance is exchangeable within that stratum. Independently draw K_h proposal indices without replacement from N_h in every stratum. This preserves the observed accepted-rate pattern and all source proposal exposures by construction; it destroys only the association between structural attributes and sign acceptance after controlling these synthetic ecological-rate/developmental cells. This is a stronger null than globally randomly shuffling the 794 acceptances. It is **not** a null for the wild world and not a new biological intervention.

Fixed RNG seed \`20261107\`, **4,999 permutations** (plus the observed assignment). Do not retune the number of permutations after viewing results.

## Primary and secondary estimands, frozen
1. **Primary distinct-ID concentration:** number K of accepted unique canonical model IDs. Original value 647. Compare to full 4,999 conditional-null distribution, its median/mean, pointwise 95% range, and one-sided lower-tail Monte Carlo p = (1 + #null[K_null <= K_obs])/(1+4999). This identifies whether compatible signs concentrate on fewer *catalogue IDs* than rate/context conditioning alone predicts, not whether those IDs are correct natural mechanisms.
2. **Primary entropy concentration:** effective Shannon number exp(−Σ p_model log p_model) across accepted canonical model IDs. Compare to the same conditional-null draws with a one-sided lower-tail test. The number of unique models and effective diversity are correlated, so **do not** treat the two tests as independent replications. Report both null distributions and signed gaps. Optional top-10/50 mass can be included as descriptive only.
3. **Secondary, full-feature mechanism diagnostics:** for *every original source structural/nuisance axis and each possible level*, compute the observed accepted count, its expected accepted count given the 81 exact strata, and its variance under finite-population hypergeometric draws within strata. Report observed minus expected accepted **share** (percentage points), enrichment (observed/conditional-expected accepted share), and conditional Z score. Predeclare axes \`edge_SD, edge_DS, cover_SF, cover_DF, cover_DS, cover_SD, support_DF, support_DS, survival, timing, reverse, behavior, litter, gate_code, refuge_order, strength\`. Do **not** add rate/context to these features (they are conditioned on by the permutation design). Include every categorical level in the output, including rare levels.
4. **Multiplicity protection for secondary features:** pre-fix eligible feature levels as those with conditional expected accepted count >=5, expected non-accepted count >=5, and conditional-null variance >1e−8. For each eligible level, calculate a null Z score using the **same analytic expected count and variance**, and report both empirical two-sided permutation p and max-|Z| family-wise adjusted p across all eligible feature-level tests (4,999 fixed permutations). Do not select a favorable mechanism or threshold after reviewing the table.
5. **Fixed descriptive robustness:** repeat the conditional-null structural concentration using the original artificial 5% minimum-survival-gated success class (426 original draws); report it as a **separate selected outcome** and do not substitute it for primary four-sign success. For source-scale sensitivity, optionally report original raw vs log acceptance classes (raw=584) but do not change primary metric. Field conditional likelihood remains entirely absent.
6. **Negative controls:** each permutation must preserve EXACT 794 accepted count, every rate×context K_h, and all 20,000 catalogue proposal exposures. All discarded/rejected source proposals remain part of the null. No accepting only certain rate conditions. Raw original target, not an acoustic-outcome fit, defines success.

## Scientific decision and manuscript guardrails
If K or Shannon diversity falls below the conditional-null distribution, claim **model-catalogue structural selectivity *beyond the preexisting rate/context signature***. If not, conclude the four-sign screen's apparent restriction to 647 IDs is compatible with rate/context weighting and proposal sampling alone. Even strong conditional-null rejection does NOT identify a uniquely correct mechanism; it may reflect correlated catalogue feature coding, rate-dependent numerical dynamics, unobserved synthetic nuisance, or 3,600-model multiplicities. Feature enrichment only demonstrates within-catalogue associations, not necessity/sufficiency or natural food-web causal effects.

Preserve G8/G11 disjoint-structure model-family positive replication, G9 571/782, G10 uncertain standardized excess loss, G5/G7 failed field-prediction support and observational R1 adult calling limitations. Do not claim accepted sources form posterior probabilities of wild ecological mechanisms. The original 647 accepted structures must be reported irrespective of G13 result, and the original ABC screen's prior dependence across G12 nine scenarios must remain visible.
