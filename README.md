# frogcs — カエルの発声・植生・三者関係

現在の研究は、北米4,248地点の発声パターンのマクロ解析と、カエル・ヤゴ・有尾類の機構シミュレーションを組み合わせるものです。

現行稿の主結果は、**有尾類の加入時期と水中期間の組合せが、植生のカエル量への効果を負から正へ反転させること**です。同一256食物網構造のモデル内で、加入時期と水中期間を独立に操作しました。植生の二機能を両方ONにする効果は、遅い加入・短い水中期間で平均logカエル量 −0.1864、早い加入・長い水中期間で +0.1163 でした。早期加入が不利益をほぼ解消し、長い水中期間が加わると利益になります。[P1の全4条件と区間](research/P1_PURE_ARRIVAL_DURATION_TRUE80_VERIFIED_RESULT_2026-11-05.md)を保持しています。

独立256構造を用いた植生機能の比較では、二機能の組合せにより4符号成立率も **3.52%から14.06%** へ増えました。一方、パターン成立に最も有利な発育条件と、カエル量に最も有利な条件は異なります。長期占有の利益も発育条件に依存します。

野外とのG4–G7比較では機構を選べる確かな予測改善には届いておらず、[G7の結果・固定仕様・不確実性](research/G7_TRAIT_COMPOSITION_RESULT_2026-11-06.md)も保持しています。鳴き声は繁殖成功、適合度は捕食者密度、景観植生は池内の隠れ場の直接測定ではありません。
