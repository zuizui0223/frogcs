現行稿の主結果は、**理想化した広域の相互作用符号を生成できても、カエル個体群に利益をもたらすとは限らず、その損得は発育条件で逆転する**ことです。同一256食物網構造のモデル内で、加入時期と水中期間を独立に操作しました。植生の二機能を両方ONにする効果は、遅い加入・短い水中期間で平均logカエル量 −0.1864、早い加入・長い水中期間で +0.1163 でした。早期加入が不利益をほぼ解消し、長い水中期間が加わると利益になります。[P1の全4条件と区間](research/P1_PURE_ARRIVAL_DURATION_TRUE80_VERIFIED_RESULT_2026-11-05.md)を保持しています。

独立256構造を用いた植生機能の比較では、歴史的に選んだ仮想率で4符号成立率が **3.52%から14.06%** へ増えました。**G8で27の率条件すべてを対応比較した結果、全条件平均の符号成立率は +2.705ポイント［+2.021,+3.410］、平均logカエル量は −0.04030［−0.04918,−0.03109］**。固定率の正の非加法性は全率条件に一般化せず、発育条件2ではカエル量への効果が正へ変わりました（+0.02521［+0.01507,+0.03543］）。全64分割・66ジョブと既存44数値の原稿QAは成功。**G9では新しく4符号を生成した782組のうち571組（73.0%）でカエル量が減少**しました。ただし**G10で率×発育条件を揃えると、非生成群への超過減少は認められず、差は−4.93ポイント［−11.28,+0.83］**でした。関係の方向は発育条件で逆転します。いずれも合成モデル内の結果であり、実測捕食率や野外因果の証明ではありません。

**ABC型POMの追加監査G12では、元の794/20,000提案が647構造に分散し、仮想率priorの再重み付けで4符号採択率が1.09〜6.85%へ変わりました。** 採択機構は自然の事後確率でなく、モデル内の候補です。G11では別の256構造において4符号生成増加とカエル量低下の両方向が再現されました。

**G13の条件付き帰無では、4符号に適合する647モデルIDは、元81率×発育条件だけで採択が決まる場合の平均712より少なく（p=0.0002）、構造の選別情報が残りました。** 一方、647種類の候補が残り、自然湿地の機構や野外ABC事後確率は特定できません。

**G14では、ABCで採択した794提案の平均応答形を地理的に分離した野外データへ適用し、uniform背景でだけ環境モデルへの追加予測改善が得られました（NLL改善+0.001155［+0.000253,+0.002427］）。target-group背景と自由な4交互作用モデルに対する頑健な優位性は確認できず、事前固定した両背景ゲートは不合格です。**

**G15でABC選別の独自性をさらに検証すると、同じNAAMP地点に対して199条件付き帰無モデルすべてに勝つのはuniform背景だけで、target-group背景では199モデルすべてに負けました。4符号だけの固定対照には両背景で勝ちましたが、独立した野外機構同定には至りません。**

野外とのG4–G7比較では機構を選べる確かな予測改善には届いておらず、[G7の結果・固定仕様・不確実性](research/G7_TRAIT_COMPOSITION_RESULT_2026-11-06.md)も保持しています。鳴き声は繁殖成功、適合度は捕食者密度、景観植生は池内の隠れ場の直接測定ではありません。
