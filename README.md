# frogcs — カエルの発声・植生・三者関係

現行稿の主結果は、**理想化した広域の相互作用符号を生成できても、カエル個体群に利益をもたらすとは限らず、その損得は発育条件で逆転する**ことです。同一256食物網構造のモデル内で、加入時期と水中期間を独立に操作しました。植生の二機能を両方ONにする効果は、遅い加入・短い水中期間で平均logカエル量 −0.1864、早い加入・長い水中期間で +0.1163 でした。早期加入が不利益をほぼ解消し、長い水中期間が加わると利益になります。[P1の全4条件と区間](research/P1_PURE_ARRIVAL_DURATION_TRUE80_VERIFIED_RESULT_2026-11-05.md)を保持しています。

独立256構造を用いた植生機能の比較では、歴史的に選んだ仮想率で4符号成立率が **3.52%から14.06%** へ増えました。**G8で27の率条件すべてを対応比較した結果、全条件平均の符号成立率は +2.705ポイント［+2.021,+3.410］、平均logカエル量は −0.04030［−0.04918,−0.03109］**。固定率の正の非加法性は全率条件に一般化せず、発育条件2ではカエル量への効果が正へ変わりました（+0.02521［+0.01507,+0.03543］）。全64分割・66ジョブと既存44数値の原稿QAは成功。**G9では新しく4符号を生成した782組のうち571組（73.0%、256構造単位95%区間65.8–79.5%）でカエル量が減る**ことも確認しました。これらは実測捕食率ではなく、合成モデル群の対応比較です。

野外とのG4–G7比較では機構を選べる確かな予測改善には届いておらず、[G7の結果・固定仕様・不確実性](research/G7_TRAIT_COMPOSITION_RESULT_2026-11-06.md)も保持しています。鳴き声は繁殖成功、適合度は捕食者密度、景観植生は池内の隠れ場の直接測定ではありません。
