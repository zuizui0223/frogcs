# Archive

This directory contains superseded submission surfaces and version-specific QA/build infrastructure retained for auditability.

Current submission authority remains at repository root / `submission/` and is defined in the top-level README.

## Contents

- `manuscripts/`: superseded JAE manuscript versions.
- `supporting_information/`: superseded Supporting Information releases.
- `title_pages/`: superseded title-page templates.
- `submission_history/`: old cover letters, checklists, reviewer matrices, handoffs and human-finalization surfaces.
- `workflows/`: version-specific or retired GitHub Actions workflows.
- `scripts/`: QA/build scripts used only by retired submission versions.
- `figures_history/`: superseded figure directories.

Scientific contracts, receipts, summaries and analysis scripts that support the current paper remain in their original locations because active reproducibility code uses those paths.

Release branches preserve the exact historical repository states. Nothing in this archive is current submission authority.
