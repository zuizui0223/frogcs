## 編集部の公式条件

[Ecology Letters 投稿規定 — Data and Code Availability](https://onlinelibrary.wiley.com/page/journal/14610248/homepage/ForAuthors.html)：

- 初回投稿時に編集者・査読者がアクセス可能な、再現用の元データ（または実際に解析した元データの部分集合）・派生データ・メタデータ・コードが必要。研究のデータとコードを合わせたリポジトリを要求する。
- 解析ファイルは各列の**英語の意味、測定単位、1行の統計単位**を説明したメタデータが必要。Zip内の `COLUMN_DICTIONARY_AUTHOR_COMPLETION_REQUIRED.tsv` はその作業表であって、まだ完成した説明ではない。
- DOIとデータ公開状況を本文・タイトルページに記載し、研究データの権利・機密を保持する。投稿時にはデータリポジトリの**private-for-peer-review**機能を利用するよう指定されている。編集部に認められる例外やエンバーゴは別途許可が必要。

## 著者本人・共著者承認が必要な作業

1. **著者と権利の確定。** 正しい著者順、貢献、所属、研究費、利害関係、研究元データの各権利を確認する。全員の投稿許可がなければ外部の公開用レコードを公開しない。環境ラスタ、GBIF提供者、一部地点情報等の再配布許諾は未確定。
2. **完全な研究アーカイブへの仕上げ。** モデル専用Zipの列辞書と環境手順を完成させ、元のNAAMP集計・環境入力・第三者の独立観測データの必要部分について、許諾または編集部が認めるアクセス代替を確認する。元文献とprovider DOI、取得コードを明記し、モデルコード・図の元データ・原R5出力も同じ査読可能な保管先で扱う。
3. **Zenodoの草稿を作成し、予約DOIと非公開査読アクセスを準備。** [公式：草稿作成](https://help.zenodo.org/docs/deposit/create-new-upload/)、[DOI予約](https://help.zenodo.org/docs/deposit/describe-records/reserve-doi/)、[Can preview draft の秘密共有リンク](https://help.zenodo.org/docs/share/link-sharing/)を参照。公式ガイドでは草稿でDOIを予約でき、共有リンクに **Can preview draft** 権限を付けられる。**予約DOIは公開済みのDOIやアクセス成功を意味しない。** Editorが要求する初回投稿時のDOI要件と矛盾がないか、実際の共有リンク・閲覧権限・保存先の取り扱いを確認する。必要ならEcology Letters編集部（投稿規定記載の問い合わせ先）に確認する。
4. **投稿原稿と著者確認を完了。** DOIと実際に査読者が閲覧できるURLを確認した後にのみデータ利用文へ転記。全著者の承認、著者論文との新規性差分、図の版、Reference数、原稿のWord/PDF proofを確認してResearch Exchangeから投稿する。

**禁止する近道：** 予約しただけのDOIを公開済みと書くこと、第三者の再配布権利を推定すること、すべての地点情報を無条件でアーカイブへ入れること、野外の鳴き声を孵化量と同一視すること、R5の仮想観測を自然界の因果検証として扱うこと。
