# Public calibration and fixed-model compatibility audit

## Objective
Inspect and, where possible, analyze source-native public data linking calling to actual abundance/stage, or independently testing pond interactions. Reassess fixed model compatibility with the new macro results without tuning model structures or claiming statistical equivalence across observables.

## Fixed comparison before calculating results
- Use already selected 1479 and reduced 1455 across all 24 saved nuisance contexts; do not choose a new catalogue winner.
- Show previously saved 1479 block13 supply-grid resolution 3/9/21 as sensitivity, not alternative fitted models.
- Compare four rank interaction coordinates with old unadjusted and new fully adjusted, pooled/within, both backgrounds, route and spatial resampling intervals. These are descriptive coordinate checks only: synthetic supply/recruitment is not suitability/calling.
- Include a zero-interaction benchmark to expose uninformative intervals. Marginal interval inclusion is neither a joint confidence test nor evidence of equality.
- Keep original sign/conditional-survival checks unchanged and report separately.
- Public data: acquire original raw files if accessible, inspect keys/stages/methods/units; never infer absent counts from blank/opportunistic records. Separate calling-density calibration, calling-detection crosswalk, and independent pond tests.
- Keep source attribution, hashes and failures. Do not modify protected frozen results.

## Deliverables
Reproducible saved-model comparison; two primary-source/raw-data audits; executable calibration/validation where supported; integrated NEE gate update specifying remaining gaps.

## Execution

Retrieved and analyzed 44 acoustic/visual count pairs and 146 stage-count pond sessions. Reused the existing INBO stage-link results without counting them as new data. Compared all 24 contexts for each of two fixed models, all saved grid resolutions and the zero-interaction benchmark. No simulator tuning. All raw-download failures and source limits retained. Positive three-way sign is no longer a mandatory revised target; observation-scale calibration and independent mechanism identification remain unmet.
