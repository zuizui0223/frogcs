## Predeclared longitudinal ecology question (complementary to published occupancy trend, not independent causation)

**Are reported anuran assemblage species lists at the same physical source Site more dissimilar between 2003–08 and 2024 than within-night independent-observer lists under matched microphone survey method?** This is *observed auditory community turnover* relative to a source-based observation-variability reference, not frog occupancy/recolonization or the effect of rainfall, local water, memory or adaptation. Its mechanism remains unidentified.

**Primary source eligibility:** exact `Site` names with valid source coordinates, between-era median coordinate displacement **≤10 m** and each-era within-site max coordinate spread **≤100 m**; choose only unambiguous events keyed by `Site × Date × Observer × Arrival_time × Method`. Use `Microphone` in **both** eras; require at least one **identical calendar month (June, July or August)**. Exclude any event with contradictory same-key no-anuran+species rows. `NA` plus source no-call code constitutes **explicit observed no call**, not inferred true biological absence. Keep all source data internal and emit only aggregate counts, no source locations or species identities.

**Anti-selection event pairing:** choose **one source event in each era per eligible site** using the pair minimizing absolute day-of-year difference (month must match, with nearest within 60 min of local survey time if available; primary ≤60 min). Tie-break purely on chronological source date, time, original observer code (lexicographic, not animal outcomes). Independently report coverage before and after ±60-minute constraint and opposite/no frogs vs positive union. Never select most similar or discordant events based on observed calls. Fixed secondary diagnostic: same-month matched method with no clock constraint, same event rule. **Do not promote the secondary if primary weak.**

**Detected-assemblage Jaccard:** within eligible sites, `J=|S_old∩S_2024|/|S_old∪S_2024|` of original nonempty detected frog taxon lists; for both genuine explicit no-call J undefined and reported separately; one none vs one nonempty ⇒ J=0. Track number of matched sites, no-call/positive pair categories, mean and median J, fraction no shared source-detected taxa. **Do not treat this as actual species extinction or colonization.** No taxonomic coarsening or arbitrary species exclusion chosen after outcomes. Source scientific label differences and effort noncomparability remain open caveats.

**Within-night observer reference:** on the **same cohort of eligible matched sites**, obtain independent observer pairs from the historical 2003–08 release at same site×date, **both Microphone** and start gaps ≤5 minutes, excluding ambiguous/mixed-sentinel opportunities. Choose max one original pair per site (earliest source date/clock then observer ID); compute J among nonempty-union paired observer species lists and separate both-zero, noting shared biological state and recording method versus cross-era differences. If at least **10 same sites** have both eligible long-term J and same-night reference J, compare means of site-wise `J_within-night−J_decades`; otherwise **do not claim normalized excess turnover**, report two descriptives on different frames only. Descriptive bootstrap over **site** clusters (5,000 resamples, seed 20261014) if n≥10, no confirmatory P values.

**Source first decisions:** record raw text status of no-anuran sentinel, source taxonomy vocabulary and candidate pairing counts. If there are fewer than 10 genuine cross-era near-synchronous same-method sites, report source feasibility rather than estimating broad ecological turnover; never retune thresholds post-outcome. The 2026 Burner et al. study already quantified northern `Acris blanchardi` occupancy changes with imperfect detection; this analysis does not rebrand that published inference.

**Proof/limitations:** original 2024 sampled June–Aug, older sample spans Mar–Aug; month matching reduces gross phenological confounding, not weather, call intensity, species detectability, observer training or recorder changes. Field site coordinates do not authenticate independence among ecological ponds. `Site` vs `Site_original` aliases cannot be pooled. No full occurrence model and no causal hydrological inference. Keep code reproducible and only anonymized aggregate output committed. If source labels fail to match across eras, report STOP.
