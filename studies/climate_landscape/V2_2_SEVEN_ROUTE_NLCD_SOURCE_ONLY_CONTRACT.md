# Seven Iowa routes: outcome-unread Annual NLCD screen v2.2

2026-10-08. **Environmental sources only.** RC6 unchanged, the previous route-climate held-out negative result frozen.

An original USGS Runs/Stops + Iowa DNR route-index cohort selected eight new response-unread routes; route **360109** failed an independent coordinate geometry audit and is excluded. Seven fixed routes remain: **360104, 360110, 360125, 360213, 360219, 360316, 360412**. All have historical recorded StopNumber and SiteID stability, with pre-2012 and post-2012 survey opportunities; neither historical physical location nor frog response has been independently confirmed.

This pre-response route source gate requests raw USGS-authored Esri-hosted **Annual NLCD Collection 1.0 (C1V0)** classification mosaics (2011, 2012, 2013), first enforcing original per-year catalogue Version/Name/OBJECTID. Every fixed site is sampled at 250m and 1000m on one common EPSG:5070 30m grid with at least 80% jointly valid pixels. Report forest class loss, forest-to-agriculture and forest-to-developed, and 2013 persistence. Fail closed rather than repair coordinates, change sources, select attractive locations or impute missing pixels.

This selection is *after seeing* exploratory mapped changes near 360417, so 2012 is **not an independently discovered region-wide ecological event**. No new-route CallingIndex/Counts.csv accessed, no land-cover effects fitted, and no proof of physical 2001–2015 station continuity. Current USGS Collection 1.2 and its confidence data remain necessary before a scientific confirmatory landscape result.
