# WFTS external-replication data request draft

**Purpose:** prospective confirmation of a frozen ecological endpoint.  
**Important:** do not request effect summaries, selected species, apparent positive routes, or any preview of the target result.

## Proposed request

Dear Wisconsin Frog and Toad Survey team,

I am preparing an independent, prospectively specified reanalysis of repeated frog-calling surveys and would like to ask whether site-level Wisconsin Frog and Toad Survey data can be made available for research use.

Before accessing the response data, I have frozen the intended eligibility criteria and analysis. The confirmatory analysis requires repeated surveys of the same permanent route stations and uses only the spatial distribution of taxon-level calling activity across those stations.

If available, I would be grateful for a dataset containing the following fields for the traditional 10-station WFTS routes:

- route identifier;
- permanent station/listening-point identifier or station number;
- survey date and year;
- survey run/seasonal period;
- frog/toad taxon;
- call index (0/blank, 1, 2, 3 as recorded);
- observer identifier if releasable in de-identified form;
- route/station latitude and longitude, or a stable station identifier sufficient to link repeated visits;
- recorded air/water temperature, wind and sky variables if available;
- any recorded rain or weather field;
- flags or notes identifying station replacement, relocation, route redesign, incomplete surveys or major protocol deviations.

A stable station identifier is more important than precise public coordinates; coordinates can remain restricted if necessary.

I am **not** requesting preliminary summaries of whether calling is stronger after rain, which species show the strongest pattern, or which routes produce the largest effect. The aim is to preserve a one-shot prospective test.

The current analysis specification is designed to be reported regardless of whether the external result supports or does not support the original pattern.

Please also let me know:
- the years for which site-level electronic records are available;
- any known protocol changes that affect station identity or call-index comparability;
- data-use, acknowledgement or co-authorship expectations;
- whether there is a preferred citation or data-use agreement.

Thank you for maintaining this unusually valuable long-term monitoring programme.
