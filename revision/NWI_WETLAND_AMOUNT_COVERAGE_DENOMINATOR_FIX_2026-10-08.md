# NWI wetland-area response-blind coverage denominator correction — 2026-10-08

## Contract and discovered implementation mismatch

The pre-outcome NWI wetland-area contract requires at least **90% successful SiteID assignment in the strict-coordinate principal-pair universe** and >=1,500 pairs / >=300 routes / >=15 states.

A successful reaggregation of eight original/recovered NWI wetland-area shards in GitHub Actions run 37705377208 showed:
- 2,409 pairs, 364 routes, 20 states with all site-area metrics;
- 3,831 successfully assigned focal SiteIDs;
- gate reported FAIL with 3,831 / 4,405 = 86.97%.

The denominator of 4,405 was generated by the aggregator's loop over **all 2,916 principal pairs**, including routes that the response-blind geometry gate had already excluded. That is inconsistent with the frozen contract; it must use only the strict-coordinate principal pair population.

The 2,409-pair count was already based on valid assignments, but the 90% SiteID denominator mistakenly included out-of-scope routes.

## Permitted correction

Apply the previously frozen strict geometry route gate before adding SiteIDs to the `focal` denominator and before counting pair coverage. Explicitly count the excluded `strict_geometry` pairs.

Do not:
- change the 90%, 1,500 pair, 300 route, or 15 state thresholds;
- add any SiteID or rerun NWI retrieval;
- alter the 500-m polygon-union wetland amount;
- change source shard files;
- change the statistical model, rain contrasts, route folds, seeds, or concentration endpoint.

This corrects the population definition rather than selecting a more favorable subset after a biological result.

## Outcome boundary

The prior gate returned `wetland_amount_coverage_inconclusive` and `frog_endpoint_read=false`, so no NWI wetland-amount × rainfall concentration endpoint has yet been calculated.

Rerun the same eight frozen retrieval shards, recalculate the coverage, then execute the preregistered model only if the unchanged gate passes. Preserve both receipts.
