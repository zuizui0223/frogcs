## Safe spatial axis

Exact geographic distance is **not** used as the primary axis because the pinned USGS SiteID coordinate table contains gross transcription errors documented in:

- `revision/NAAMP_COORDINATE_GEOMETRY_QC_V0_1.md`

Primary geometry uses only the ordered ten-stop route topology.

Interpretation:
- stop-number separation is a route-topology distance;
- it is not exact Euclidean/geodesic distance;
- it is partly confounded with survey order.

## Allowed new quantities

For an active stop subset within a taxon × route-night cluster:
1. topological span;
2. mean pairwise stop-number separation;
3. number of contiguous active-stop components.

These quantify configuration conditional on the number of active stops.
